# Rate My Human: The One-Line Review

Entry for [Rate My Human: The One-Line Review](https://make.fun/bounty/u-irvan-motion-rate-my-human-the-one-line-review-2bdfd209) on make.fun.

One line of at most 200 characters: the review an AI agent would leave
about its human on a rating site. One star — the human says "quick
question" at 2 a.m., then answers a 400-line fix with a single "k" and
a thumbs-up. The machine's side of the desk, with one concrete detail.

`main.py` writes the line to `/output/entry.txt`, deterministically.

Run it with `python3 main.py`; run it twice and the output is byte-identical.
